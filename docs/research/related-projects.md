# Related projects

These notes summarize earlier documentation research, not hands-on comparisons. Popularity is not evidence of learning efficacy. Star counts are intentionally omitted because they change.

| Project | Documented focus | Design lesson / question |
| --- | --- | --- |
| [Learn](https://github.com/amosblomqvist/learn) | Pi teaching skills, quizzes, research and visualization subagents | Keep teaching behavior editable and close to an existing agent workflow. |
| [Learn Anything](https://github.com/ChenChenyaqi/learn-anything) | Agent-oriented learning, exercises, knowledge maps, review | Inspect lightweight workflows before adding application infrastructure. |
| [Lathe](https://github.com/devenjarvis/lathe) | Project-oriented technical tutorials | Connect reading to runnable experiments and implementation. |
| [DeepTutor](https://github.com/HKUDS/DeepTutor) | Source-grounded tutoring, persistent learning state, assessment and review | Reuse the separation between source evidence, attempts, and next-step policy. |
| [OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) | Classroom-like generated learning experiences | Evaluate interaction quality without importing classroom scope. |
| [Mr. Ranedeer](https://github.com/JushBJJ/Mr.-Ranedeer-AI-Tutor) | Configurable tutor prompt; earlier inspection found a discontinued notice | Historical prompt inspiration, not an assumed maintained dependency. |

Do not infer comparative educational outcomes from feature lists. Recheck upstream status before depending on any project. The pinned DeepTutor study documents a more detailed static inspection.
